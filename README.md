# Exposure Report Tool

A small desktop app for Toronto Professional Fire Fighters' Association Local 3888 members. It reads your Incident Listing PDF and gets your exposure reports ready to submit, so you don't have to type each one by hand.

## Download

Get the latest version from the [Releases page](https://github.com/brianknorris/Exposure-Report-Tool-Downloads/releases/latest).

- Mac: download the `.dmg` file. Pick `Exposure-Report-Tool-<version>-arm64.dmg` for newer (Apple Silicon) Macs, or `Exposure-Report-Tool-<version>-x64.dmg` for older (Intel) Macs.
- Windows: download `Exposure-Report-Tool-Setup-<version>-x64.exe`.

## What you need

Ask your captain for your Incident Listing PDF (Fire calls, all dates).

## Install on Mac

1. Open the `.dmg` and drag Exposure Report Tool into Applications.
2. Open the app once. macOS will say it can't verify the app. Click Done.
3. Open System Settings, then Privacy & Security.
4. Scroll down to the message about Exposure Report Tool and click Open Anyway.
5. Enter your Mac password if asked. A second box appears asking again; click Open Anyway once more.
6. The app opens. You only need to do this once.

## Install on Windows

1. Run the installer. Windows may show a blue "Windows protected your PC" screen.
2. Click More info, then Run anyway.
3. Follow the installer steps, then open Exposure Report Tool from the Start menu.

The app isn't signed with a paid certificate, which is why both systems show a warning the first time.

## Privacy

Your data stays on your computer. The app only talks to the TPFFA site, the exposure form (and the Google reCAPTCHA it uses), and GitHub to check for updates.
